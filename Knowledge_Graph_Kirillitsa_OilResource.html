Процесс работы с кодом

⚠ Ревнивый IT-отдел клиента (Пётр). Никаких сторонних библиотек, подозрительного кода.

Цепочка контроля: Ширкевич делает → Сайфудинов ревьюит → Алёна валидирует через Claude Code (QA + пентестер) → в Dev.

Деплой:

  1. Василию: проверить место на сервере
  2. Бэкап через админку Битрикс → скачать → развернуть локально
  3. Все правки на локальной копии
  4. Перед заливкой: уведомить клиента
  5. Клиент обновляет контент вечером и до четверга обеда
  6. Каждый раз свежая копия прода
  7. После заливки — удалить бэкап с сервера

10. Пробелы и возможности

Критические пробелы

  • ● Полное отсутствие Schema.org → 0 Rich Snippets
  • ● Нет Meta Description → −30–40% CTR
  • ● /investors/ не существует на OR
  • ● hreflang не настроен → каннибализация
  • ● Sitemap на HTTP

Стратегические возможности

  • ● 100+ пресс-релизов OR → Яндекс.Новости
  • ● Инвесторский трафик (глубина 5.2, отказы 12%)
  • ● Продуктовые стр. (дизель оптом = 1,000–2,000)
  • ● Каталог 1С (июль) → покрытие семантики
  • ● Английская версия .com → пик запросов
  • ● Платформа брендов → ~7 млн ₽ проект

11. Ключевые решения (встреча 31.03.2026)

  1. Фокус = зарабатывание денег. Каждая единица приносит доход.
  2. Toimi = органический рост. Прежний объём контента не нужен.
  3. Только российские проекты. Зарубежные пресейлы отказались.
  4. Апрель = техничка. Формировать задачи для разработчиков.
  5. Отчитываться раз в 1–2 недели, начиная с конца апреля.
  6. Рассмотреть SEO на 3 доменах (ru/com/cn) — «делать один раз, получать три раза».
  7. Каталог продукции (1С) — июль, ~2 млн ₽.
  8. Платформа брендов — апрель+, ~7 млн ₽.

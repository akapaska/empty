## Правила

1. **Описательный текст** — что изображено
2. **С ключевыми словами** — естественно, без спама
3. **На русском языке**
4. **5–15 слов**
5. **Декоративные** (стрелки, маски, разделители, SVG-иконки) → `alt=""`
6. **Трекинг-пиксели** (Яндекс.Метрика и т.п.) → не трогать

## Инструкция для внедрения

1. Пройти по всем страницам обоих сайтов
2. Для каждого `<img>` — добавить alt по таблицам выше
3. Для страниц не описанных выше — применять общие правила
4. Для динамических изображений (новости, пресс-релизы) — настроить автогенерацию alt из заголовка: `alt="{Заголовок новости} — Оил Ресурс"`
5. Проверить: DevTools → Ctrl+F → `alt=""` (должен быть только на декоративных)

## Отдельно по внутренним страницам

Страницы /branch/petroleum/, /branch/agro/, /branch/it/, /investors/, /press-center/, /contacts/ — пройти отдельно после основных. Применять принцип:
- Фото объектов/процессов → описательный alt с ключевыми словами страницы
- Иконки/декор → `alt=""`
- Графики/диаграммы → `alt="Название графика — ключевые цифры"`
